# Lars Strömberg

Software developer and educator building AI tools and self-hosted infrastructure.
Based in Gothenburg, Sweden.

## What I build

- Agent workflows, MCP servers and RAG systems with local inference.
- Self-hosted infrastructure: a three-node Proxmox/Ceph cluster, GitLab CI and tested backup recovery.
- Tools for education: course material generation, automated repository assessment and document workflows.

I run DSVE AB and take responsibility for architecture, development and operations.
My current focus is reliable, secure and cost-controlled LLM systems.

Much of my work lives in self-hosted GitLab and private repositories.
